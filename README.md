# 🚀 Claude CCA Roadmap

Interactive roadmap for **Claude Certified Architect – Foundations (CCA)** exam.  
Track progress, learn domain-wise topics, validate with quizzes — all in one clean UI.

---

## 🌐 Website

[**claude-cca-roadmap.vercel.app**](https://claude-cca-roadmap.vercel.app/)

---

## 🧠 Overview

Preparing for Claude CCA is fragmented:
- Docs spread across domains  
- No structured checklist  
- No progress visibility  

This project solves it with:
- Structured domain-wise roadmap  
- Checklist-based learning  
- Integrated quizzes  
- Visual progress tracking  

---

## ✨ Features

- ✅ 5-domain roadmap (exam-aligned)
- ✅ Expandable sidebar navigation
- ✅ Learning + Quiz per chapter
- ✅ Tick-based completion tracking
- ✅ Real-time progress bar (%)
- ✅ Dark / Light mode
- ✅ LocalStorage persistence
- ✅ Mobile responsive UI

---

## 🏗️ Tech Stack

- React (Vite)
- Tailwind CSS
- Lucide Icons
- LocalStorage
---

## 🧪 How It Works

- Each topic = checklist item  
- Mark complete → stored locally  
- Progress auto-calculated  
- Quiz validates understanding  

---
